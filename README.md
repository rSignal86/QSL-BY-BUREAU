## From ViewSort to QSL BY BUREAU

This project is the natural evolution of *ViewSort*.

ViewSort focused on digital sorting.

QSL BY BUREAU focuses on one clear mission:

> Get your QSL cards ready for bureau shipping — correctly and efficiently.

The new name makes the purpose obvious.  
This is not just a viewer.  
This is a logistics assistant.

Quite serious logistics.

---

## Why use it?

Because manual bureau sorting is:

- Taking time  
- easy to mess up  
- costing you money if done wrong  

QSL BY BUREAU helps you:

- Automatically detect country from prefix  
- Warn you about non-bureau destinations  
- Highlight unknown prefixes  
- Assign serial numbers  
- Generate printable country strips  
- Generate a clean statistics sheet  

All in your browser.

No spreadsheets.  
No manual grouping.  
No chaos.

Snitcher is watching. Mistakes will be noticed.

---

## How it works

1. Enter callsign  
2. Press ENTER  
3. Repeat  
4. Drink soda
5. Generate labels  
6. Ship with confidence  

That’s it.
